# SCT_WD_1 — Nexus Digital Studio Landing Page
A modern, fully responsive landing page for a fictional digital studio called **Nexus**, built with pure HTML and CSS (no frameworks).

## Task Description

TASK 01
RESPONSIVE LANDING PAGE
Create an interactive navigation menu that changes color or style when scrolled or when hovering over a menu item.
The navigation menu should have a fixed position and be visible on all pages.

## Features

- Fixed responsive navigation bar with scroll effect and mobile hamburger menu
- Animated hero section with gradient background and grid overlay
- Services section with 4 cards (Brand Design, Web Development, Product Design, Growth Strategy)
- About section with animated blob visual
- Contact form with name, email, and message fields
- Smooth scroll-reveal animations on sections
- Fully mobile responsive layout

## Tech Stack

- **HTML5**
- **CSS3** (custom properties, grid, flexbox, keyframe animations)
- **JavaScript** (scroll effects, mobile menu, form interaction)
- **Google Fonts** — Fraunces & Space Grotesk
